# Bayesian penguins
## Introduction to Bayesian statistics in R and Stan
This repository contains an introductory tutorial to [`cmdstanr`](https://github.com/stan-dev/cmdstanr) using data from [`palmerpenguins`](https://github.com/allisonhorst/palmerpenguins) and can be cloned to RStudio as an R project. The folders `R` and `Stan` contain the respective scripts.
